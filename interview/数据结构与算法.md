### 2.1 反转链表（迭代 + 递归两版）
```cpp
// 迭代: 三指针滚动, O(n) 时间 O(1) 空间 —— 首选写法
ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    while (head) {
        ListNode* nxt = head->next;   // ① 先存 next, 否则改完指针就丢了
        head->next = prev;            // ② 反转当前指针
        prev = head;                  // ③ 滚动
        head = nxt;
    }
    return prev;                      // 原尾节点成为新头
}

// 递归: 思路题面(超时/栈深时说明), 面试写迭代更稳
ListNode* reverseListRec(ListNode* head) {
    if (!head || !head->next) return head;
    ListNode* newHead = reverseListRec(head->next);  // 先把后面整段翻好
    head->next->next = head;                         // 后继指回自己
    head->next = nullptr;                            // 自己变成尾
    return newHead;
}
```

### 2.2 判环 + 找入环点（快慢指针, 数学题）
```cpp
ListNode* detectCycle(ListNode* head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {                 // 相遇 → 有环
            slow = head;                    // ★ 一个回起点, 一个留相遇点
            while (slow != fast) {          // 同速前进, 再次相遇即入环点
                slow = slow->next;
                fast = fast->next;
            }
            return slow;
        }
    }
    return nullptr;                         // fast 走到头 → 无环
}
```
**为什么第二阶段能相遇在入环点（面试要能推导）**：设起点到入环点距离 `a`，环长 `b`。相遇时快指针走了 `a + b + k·(环内)`……核心结论：**相遇点到入环点的距离 ≡ 起点到入环点的距离 (mod 环长)**，所以"一个从起点、一个从相遇点同速走"必然在入环点碰头。答不出推导就说结论 + "可以拿纸推"，比硬编强。

### 2.3 合并两个有序链表（归并的链表版）
```cpp
ListNode* mergeTwoLists(ListNode* a, ListNode* b) {
    ListNode dummy(0);                 // ★ 哨兵头: 免去"第一个节点是谁"的特判
    ListNode* tail = &dummy;
    while (a && b) {
        if (a->val <= b->val) { tail->next = a; a = a->next; }
        else                  { tail->next = b; b = b->next; }
        tail = tail->next;
    }
    tail->next = a ? a : b;            // 接上剩余整段(不用逐节点)
    return dummy.next;
}
// 变体: 合并 K 个有序链表 → 优先队列(小顶堆)放 K 个头, O(N log K)；分治两两合并同复杂度
```

### 2.4 删除倒数第 N 个节点（双指针 + 哨兵）
```cpp
ListNode* removeNthFromEnd(ListNode* head, int n) {
    ListNode dummy(0);
    dummy.next = head;
    ListNode *slow = &dummy, *fast = &dummy;
    for (int i = 0; i <= n; ++i) fast = fast->next;   // fast 先走 n+1 步
    while (fast) { slow = slow->next; fast = fast->next; }  // 同走, fast 到尾时 slow 在待删前驱
    ListNode* del = slow->next;
    slow->next = del->next;                            // 链表删除 = 改前驱的 next
    delete del;
    return dummy.next;                                 // ★ 哨兵: 删头节点也能统一处理
}
```
**链表题的通关密码**（面试速记）：① 哨兵头节点消除头插/删头特判；② 双指针/快慢指针解决"倒数""中点""判环"；③ 改指针前先存 next；④ 画图！纸上一画就不会错。

## 3. 手撕集训 B：二分查找（"一看就会、一写就死循环"区）

### 3.1 两个万能模板（背下来覆盖 90% 场景）
```cpp
// 模板一: 找"第一个 >= target"的位置 (lower_bound 语义, 左闭右开)
int lowerBound(const std::vector<int>& a, int target) {
    int lo = 0, hi = (int)a.size();          // 左闭右开: [lo, hi)
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;        // ★ 防 int 溢出; 也统一收敛方向
        if (a[mid] < target) lo = mid + 1;
        else                 hi = mid;       // a[mid] >= target: 收缩右界, mid 保留
    }
    return lo;   // lo == 第一个 >= target 的下标; == size() 表示都比 target 小
}

// 模板二: 找"最后一个 <= target"的位置
int upperBoundLE(const std::vector<int>& a, int target) {
    int lo = 0, hi = (int)a.size() - 1;      // 左闭右闭: [lo, hi]
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] <= target) lo = mid + 1;  // mid 可能命中, 记录后可继续向右
        else                  hi = mid - 1;
    }
    return hi;   // hi 即答案; < 0 表示都比 target 大
}
```
**防死循环三律**（面试现场 debug 必备）：
1. `mid` 一律写 `lo + (hi - lo) / 2`（防溢出 + 只向 lo 倾斜）；
2. 循环条件与收缩方向配套：`lo < hi` 配"`hi = mid` 不动 mid"；`lo <= hi` 配"`hi = mid - 1`"；
3. 写完先在心里跑三组数据：**空数组、单元素、target 在首/尾**。

### 3.2 高频变体
```cpp
// 变体1: 有序数组的搜索 (标准题) —— 命中即返回 mid
// 变体2: 搜索旋转排序数组 —— 每步判断哪一半是"有序的一半", 决定丢弃哪侧
int searchRotated(const std::vector<int>& a, int target) {
    int lo = 0, hi = (int)a.size() - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] == target) return mid;
        if (a[lo] <= a[mid]) {                       // 左半有序
            if (a[lo] <= target && target < a[mid]) hi = mid - 1;
            else lo = mid + 1;
        } else {                                     // 右半有序
            if (a[mid] < target && target <= a[hi]) lo = mid + 1;
            else hi = mid - 1;
        }
    }
    return -1;
}
// 变体3: 求平方根(整数, 二分答案法) —— "满足条件的最小值/最大值"都能二分,
//        条件只需单调性(如 x*x <= n), 这就是"二分答案"的思想
// 变体4: 旋转数组找最小值 —— 比较 a[mid] 与 a[hi], 收缩方向同款套路
```
**面试关联**：量化场景里的"二分"经常是**二分答案 + 单调校验**（找最小可行保证金、最大可成交量），思路一样，题干换了皮。

## 4. 手撕集训 C：栈 / 队列 / 哈希（含 LRU 终极高频题）

### 4.1 单调栈（每日温度 / 接雨水 / 柱状图最大矩形）
```cpp
// 每日温度: 对每个 i 求"下一个更高温度"的下标差 → 单调递减栈
std::vector<int> dailyTemperatures(const std::vector<int>& t) {
    std::vector<int> ans(t.size(), 0);
    std::vector<int> st;                       // 存下标, 栈内温度单调递减
    for (int i = 0; i < (int)t.size(); ++i) {
        while (!st.empty() && t[i] > t[st.back()]) {
            ans[st.back()] = i - st.back();    // 弹出即结算
            st.pop_back();
        }
        st.push_back(i);
    }
    return ans;                                // 剩下的栈内元素 = 后面没有更高温, 保持 0
}
// 套路一句话: 找"下一个更大/更小" → 单调栈, 每元素进出栈各一次, O(n)
```

### 4.2 LRU 缓存（哈希 + 双向链表，手撕率 TOP3）
```cpp
#include <list>
#include <unordered_map>

class LRUCache {
    int cap_;
    // list 头部 = 最近使用(MRU), 尾部 = 最久未用(LRU)
    std::list<std::pair<int, int>> items_;   // (key, value)
    std::unordered_map<int, std::list<std::pair<int,int>>::iterator> map_;
public:
    explicit LRUCache(int capacity) : cap_(capacity) {}

    int get(int key) {
        auto it = map_.find(key);
        if (it == map_.end()) return -1;
        // splice: O(1) 把节点搬到头部, 不拷贝数据、不失效迭代器(add 到 begin)
        items_.splice(items_.begin(), items_, it->second);
        return it->second->second;
    }

    void put(int key, int value) {
        auto it = map_.find(key);
        if (it != map_.end()) {              // 已存在: 更新值 + 提到头部
            it->second->second = value;
            items_.splice(items_.begin(), items_, it->second);
            return;
        }
        if ((int)items_.size() == cap_) {    // 满: 淘汰尾部(最久未用)
            map_.erase(items_.back().first);
            items_.pop_back();
        }
        items_.emplace_front(key, value);    // 新节点放头部
        map_[key] = items_.begin();
    }
};
```
**讲解（面试必说）**：
- 为什么是"哈希 + 双向链表"：哈希给 O(1) 定位节点；双向链表给 O(1) 摘除/移动（单向链表要 O(n) 找前驱）；
- `splice` 是这题的点睛 API（把节点从中间无损搬到头部）；用裸指针手写双向链表也一样要会（两个哨兵节点彻底消灭边界特判——和 OS 笔记里的队列哨兵是同一个思路！）；
- **线程安全版**：加互斥锁是最简单答案；高并发场景（如行情缓存）常用**分片 LRU**（N 个 LRU 各配一把锁，按 key 哈希分流）——说出这个给面试官加分。

### 4.3 哈希表原理速答
- 冲突处理两大流派：**拉链法**（链地址，std::unordered_map 多数实现）与**开放寻址**（线性/二次探测，存量大时缓存友好）；
- 负载因子（元素/桶数）超阈值触发 **rehash**：桶数组扩倍 + 全部元素重散列——这是"unordered_map 迭代器在插入后可能全部失效"的根因；
- 均摊 O(1) 的来源：扩容成本按翻倍摊还；
- 工程细节：自定义 key 要同时提供 `hash` 与 `==`；`unordered_map` 最坏 O(n)（被恶意构造的哈希碰撞攻击，生产 server 用随机种子防）。

### 4.4 环形缓冲（量化岗特别爱考）
思路与完整代码见 `操作系统.md` §10.2（SPSC 无锁环：单调索引 + 位与取模 + cache line 隔离 + acquire/release）。这里补一句面试话术：
> "环形缓冲的收益是 O(1) 且无分配：定长数组、单调递增的读写索引、`& (N-1)` 代替取模；单生产单消费时不需要锁，靠 acquire/release 配对发布数据；head/tail 分置不同 cache line 防伪共享。"

## 5. 手撕集训 D：排序与 TopK（白板常客）

### 5.1 快速排序（含随机化 pivot + 分区讲解）
```cpp
#include <vector>
#include <cstdlib>

int partition(std::vector<int>& a, int lo, int hi) {
    // ★ 随机化: 与 hi 交换后以 a[hi] 为 pivot —— 防"有序数组 + 固定 pivot"退化 O(n²)
    std::swap(a[hi], a[lo + std::rand() % (hi - lo + 1)]);
    const int pivot = a[hi];
    int i = lo;                                  // i = 已确认 < pivot 区域的右边界+1
    for (int j = lo; j < hi; ++j) {
        if (a[j] < pivot)                        // 发现更小的 → 换到 < 区域末尾
            std::swap(a[i++], a[j]);
    }
    std::swap(a[i], a[hi]);                      // pivot 归位: 左边全小, 右边全大
    return i;                                    // 返回 pivot 最终下标
}

void quickSort(std::vector<int>& a, int lo, int hi) {
    if (lo >= hi) return;
    const int p = partition(a, lo, hi);
    quickSort(a, lo, p - 1);
    quickSort(a, p + 1, hi);
}
```
**讲解要点**：
- 核心不变式：`[lo, i)` 全部 `< pivot`，`[i, j)` 全部 `>= pivot`——面试照着这个讲分区就出不了错；
- 平均 O(n log n)，最坏 O(n²)（每次 pivot 都是极值）；随机化后最坏概率极低；
- 优化顺序：小区间切插入排序 → 三路划分（大量重复元素场景）→ 尾递归消除；
- 稳定性：**快排不稳定**（分区时交换会跨过相等元素）。

### 5.2 归并排序（稳定 + 链表友好）
```cpp
void mergeSort(std::vector<int>& a, std::vector<int>& tmp, int lo, int hi) {
    if (lo >= hi) return;
    const int mid = lo + (hi - lo) / 2;
    mergeSort(a, tmp, lo, mid);
    mergeSort(a, tmp, mid + 1, hi);
    // merge: 双指针归并到 tmp, 再拷回 (可以直接在合并时判断有序性做优化)
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi)
        tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];   // ★ <= 保证稳定
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= hi)  tmp[k++] = a[j++];
    std::copy(tmp.begin() + lo, tmp.begin() + hi + 1, a.begin() + lo);
}
```
**考点**：O(n log n) 恒成立（无最坏退化）、稳定（`<=` 是关键）、空间 O(n)；**外排序**（大文件分块排序再多路归并）和**链表排序**（快慢指针找中点 + 合并有序链表）都用它。

### 5.3 堆与 TopK（大顶堆手写 + 三种解法对比）
```cpp
// 手写大顶堆: 上浮(push) / 下沉(pop)
class MaxHeap {
    std::vector<int> h_;                    // 0 号不用, 方便父子下标计算: i→2i/2i+1
public:
    void push(int v) {
        h_.push_back(v);
        int i = (int)h_.size() - 1;
        while (i > 1 && h_[i] > h_[i / 2]) { std::swap(h_[i], h_[i / 2]); i /= 2; }
    }
    int pop() {
        int top = h_[1];
        h_[1] = h_.back(); h_.pop_back();
        int i = 1, n = (int)h_.size() - 1;
        while (2 * i <= n) {
            int c = 2 * i;
            if (c + 1 <= n && h_[c + 1] > h_[c]) ++c;      // 选更大的孩子
            if (h_[i] >= h_[c]) break;
            std::swap(h_[i], h_[c]); i = c;
        }
        return top;
    }
    bool empty() const { return h_.size() <= 1; }
};

// TopK 大 的三种解法(面试把三种都说出来再挑):
// ① 全排序 O(n log n) —— 最慢, 别选
// ② 小顶堆, 堆里永远<=K个: O(n log K), 空间 O(K) —— 数据流/海量数据的标准答案
// ③ 快速选择(快排分区改版): 平均 O(n), 但要能改数组 —— 一次性数据的答案
int topKByHeap(const std::vector<int>& a, int k) {
    std::priority_queue<int, std::vector<int>, std::greater<int>> pq;  // 小顶堆
    for (int v : a) {
        pq.push(v);
        if ((int)pq.size() > k) pq.pop();   // 挤掉最小的 → 留下的就是最大的 K 个
    }
    return pq.top();                        // 第 K 大
}
```
**面试追问预案**：
- "海量数据取 TopK / 找重复 URL？"→ 哈希分桶到多机/多文件（同 key 必落同桶）+ 每桶内堆/哈希统计（分治思想）；
- "第 K 大用堆是 O(n log K)，还能更快吗？"→ 快速选择平均 O(n)（partition 定位第 K 位，只递归一侧）；
- "堆和平衡树的区别？"→ 堆只要局部序（看顶 O(1)），插入删除 O(log n) 且常数更小；需要有序遍历/区间查询才上树。

## 6. 手撕集训 E：树与图

### 6.1 二叉树遍历（递归 + 迭代两版，前中后序一套说清）
```cpp
struct TreeNode { int val; TreeNode *left, *right; };

// 递归三序: 唯一区别是"访问根"的位置
void preOrder(TreeNode* r, std::vector<int>& out)  { if (!r) return; out.push_back(r->val); preOrder(r->left, out); preOrder(r->right, out); }
void inOrder(TreeNode* r, std::vector<int>& out)   { if (!r) return; inOrder(r->left, out); out.push_back(r->val); inOrder(r->right, out); }
void postOrder(TreeNode* r, std::vector<int>& out) { if (!r) return; postOrder(r->left, out); postOrder(r->right, out); out.push_back(r->val); }

// 迭代中序(显式栈): 面试常要求"不用递归"
std::vector<int> inOrderIter(TreeNode* root) {
    std::vector<int> out;
    std::vector<TreeNode*> st;
    TreeNode* cur = root;
    while (cur || !st.empty()) {
        while (cur) { st.push_back(cur); cur = cur->left; }  // 一路向左压栈
        cur = st.back(); st.pop_back();
        out.push_back(cur->val);                             // 弹出即访问(中序位置)
        cur = cur->right;                                    // 转右子树
    }
    return out;
}

// 层序遍历(BFS): 队列 + 分层记录 size
std::vector<std::vector<int>> levelOrder(TreeNode* root) {
    std::vector<std::vector<int>> res;
    if (!root) return res;
    std::queue<TreeNode*> q; q.push(root);
    while (!q.empty()) {
        int sz = (int)q.size();              // ★ 先记 size: 这一批就是"同一层"
        std::vector<int> level;
        while (sz--) {
            TreeNode* n = q.front(); q.pop();
            level.push_back(n->val);
            if (n->left)  q.push(n->left);
            if (n->right) q.push(n->right);
        }
        res.push_back(std::move(level));
    }
    return res;
}
```
**相关高频题一句话**：验证 BST = 中序递增（或递归传上下界）；二叉树最大深度/直径 = 后序递归；最近公共祖先 = 后序找两侧命中；序列化 = 前序 + 空节点占位。

### 6.2 并查集（路径压缩 + 按秩合并，模板背下来）
```cpp
class DSU {
    std::vector<int> parent_, rank_;
public:
    explicit DSU(int n) : parent_(n), rank_(n, 0) {
        for (int i = 0; i < n; ++i) parent_[i] = i;
    }
    int find(int x) {                       // 路径压缩: 顺便把整条链拍平
        return parent_[x] == x ? x : parent_[x] = find(parent_[x]);
    }
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;           // 已在同集合(如: 这条边会成环)
        if (rank_[a] < rank_[b]) std::swap(a, b);
        parent_[b] = a;                     // 秩小的挂到秩大的下面
        if (rank_[a] == rank_[b]) ++rank_[a];
        return true;
    }
};
// 复杂度: 近 O(1) (阿克曼反函数); 用途: 连通分量、Kruskal 最小生成树、账户合并、"等价类"题
```

## 7. 多线程手撕（呼应上文 2.1 按序打印）

### 7.1 工具箱对比：四件套各自什么时候用
| 工具 | 语义 | 适用 | 注意 |
|---|---|---|---|
| 条件变量 + mutex | "等某条件成立" | 有共享状态的顺序/交替控制 | wait 必须放 while 里查谓词 |
| 信号量(sem_t) | 通行证计数 | 顺序放行、资源计数 | 无所有者概念; 可跨进程 |
| 原子自旋(atomic) | 无锁标志 | 极短等待、低延迟 | 等待久会烧 CPU; 加 pause/退避 |
| promise/future | 一次性值传递 | 线程间"交结果" | 语义最清晰, 适合一次性事件 |

### 7.2 上文 1114 按序打印 · 参考实现（条件变量版）
```cpp
#include <mutex>
#include <condition_variable>
#include <functional>

std::mutex mtx;
std::condition_variable cv;
int turn = 1;                               // 共享"轮到谁"的谓词

void first(std::function<void()> printFirst) {
    std::unique_lock<std::mutex> lk(mtx);
    cv.wait(lk, [] { return turn == 1; });  // while 谓词等待(内部即循环检查)
    printFirst();
    turn = 2;
    cv.notify_all();
}
void second(std::function<void()> printSecond) {
    std::unique_lock<std::mutex> lk(mtx);
    cv.wait(lk, [] { return turn == 2; });
    printSecond();
    turn = 3;
    cv.notify_all();
}
void third(std::function<void()> printThird) {
    std::unique_lock<std::mutex> lk(mtx);
    cv.wait(lk, [] { return turn == 3; });
    printThird();
}
// 另两种解法(面试说出取舍即满分):
// ① 原子变量自旋: turn.load() 判断 —— 无锁但忙等, 适合该题这种"极短任务"
// ② 两个信号量/eventfd: first 结束后 post 给 second —— 计数语义直观, 可扩到进程间
```

### 7.3 交替打印奇偶（1~100，两个线程）
```cpp
// 与 1114 同构: 只是"谓词"从"轮到谁"变成"该谁打印 + 打到几了"
void worker(bool isOdd) {
    for (; cur <= 100; ) {
        std::unique_lock<std::mutex> lk(mtx);
        cv.wait(lk, [&] { return cur <= 100 && (cur % 2 == 1) == isOdd; });
        if (cur > 100) return;
        std::cout << (isOdd ? "odd" : "even") << ": " << cur++ << "\n";
        cv.notify_all();
    }
}
```
**多线程题的万能三步**：定义共享状态（谓词）→ 用"锁 + 条件变量 while 等待"或"原子"保护 → 每次修改状态后 notify。生产者消费者完整实现见 `操作系统.md` §3.6/§10。

### 8.1 位运算小抄（面试高频四连）

```cpp
// 位图(bitmap): 1 亿个整数去重/存在性 → 12.5 MB 位数组
class BitMap {
    std::vector<uint64_t> bits_;
public:
    explicit BitMap(size_t n) : bits_((n + 63) / 64, 0) {}
    void set(size_t i)   { bits_[i >> 6] |=  (1ull << (i & 63)); }
    bool test(size_t i)  { return bits_[i >> 6] >> (i & 63) & 1; }
};
```

### 8.2 布隆过滤器（"可能存在/一定不存在"）
- 哈希 k 个函数把元素映射到位图的 k 个位；查询：k 位全 1 → **可能存在**（假阳性），有一位 0 → **一定不存在**（无假阴性）；
- 参数速记：位数组 `m ≈ -n·ln p / (ln2)²`，哈希个数 `k = (m/n)·ln2`；期望误判率 p 取 0.01 时约 `m/n ≈ 9.6 bits`，k ≈ 7；
- 用途：缓存穿透防护、爬虫 URL 去重、行情代码白名单预筛。

### 8.3 海量数据处理四板斧
1. **哈希分桶**：同 key 必落同一桶（`hash(key) % N`），大问题拆小后单机可解（TopK、去重、统计）；
2. **位图 / 布尔阵列**：判断"存在性"/去重，空间降百倍；
3. **外排序**：分块排序 + k 路归并（大文件排序）；
4. **近似结构**：布隆过滤器、HyperLogLog（基数估计）——能容忍误差时换空间。

## 9. 量化特色数据结构题（面试官偏爱）

- **订单簿（Order Book）**：`价格 → 档位` 用有序结构（对 std::map 即红黑树：找最优价 = `rbegin()`；区间快照 = 迭代器区间）；**同价位 FIFO** 再挂一个队列（时间优先）；
  - 追问预案："为什么不用哈希？"——需要**有序**找最优价/区间；"map 和 unordred_map 在热路径取舍？"——数据量小时 map 迭代友好，海量档位时哈希 + 维护最优价索引；
- **撮合引擎**：买卖两侧各自"价格优先队列 + 同价 FIFO"，本质是双向优先队列/双端队列组合；
- **定时器**：超时管理常用**最小堆**（O(log n) 插入/取最早）；超大规模且时间粒度粗用**时间轮**（O(1)）；
- **行情缓存**：LRU（见 §4.2）+ 分片降锁竞争；增量更新用"快照 + 差值"；
- **复盘/回放**：环形缓冲 + 序号哈希表（见 `计算机网络.md` §13 的 Replay Buffer 骨架）。

> **通用答题模板**（任何"设计题"都套）：先澄清需求（并发量、延迟目标、数据规模）→ 列候选结构并对比复杂度 → 说明取舍 → 补边界（空、回绕、溢出、并发）。
