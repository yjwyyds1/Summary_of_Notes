# 练习：用完美转发写一个消息工厂

← [[学习/学习导航/2026-10-30-学习导航|今日导航]] · [[八股测试/2026-10-30#EX-20261030-001|回到练习题]] · 参考答案：[[学习/2026-10-30/示例代码/03_forwarding|03_forwarding 阅读版]]

## 题目

行情链路里有一组事件类型：

```cpp
struct QuoteEvent { std::string symbol; double price; int qty; };
struct TradeEvent { std::string symbol; double price; int qty; };
```

要求实现：

```cpp
template <typename EventT, typename... Args>
Event make_event(Args&&... args);
```

1. 返回 `EventT`，用 `std::forward<Args>(args)...` 构造；
2. 传左值 `std::string` 时应复制，传 `std::move(name)` 时应移动——不能一律复制；
3. 用 `static_assert` 或返回类型约束，保证 `EventT` 只能是你允许的事件类型；
4. 说明：如果把这个工厂放进 `std::function` 里存起来，会多出哪些开销？

## 先自己想

提示：`Args&&...` 是转发引用；`std::forward<Args>(args)...` 展开到构造函数；约束可以用 `std::enable_if` 或 `if constexpr`。

> [!tip]- 参考答案
>
> **基本实现**
>
> ```cpp
> template <typename EventT, typename... Args>
> EventT make_event(Args&&... args) {
>     static_assert(std::is_same_v<EventT, QuoteEvent> ||
>                   std::is_same_v<EventT, TradeEvent>,
>                   "只允许 QuoteEvent / TradeEvent");
>     return EventT{std::forward<Args>(args)...};
> }
> ```
>
> **为什么能区分复制与移动**
>
> - 传 `std::string name`（左值）：`Args` 推成 `std::string&`，`forward` 传左值 → 复制；
> - 传 `std::move(name)`（右值）：`Args` 推成 `std::string`，`forward` 传右值 → 移动。
>
> **验证方式**：`make_event<QuoteEvent>(name, 10.5, 100)` 之后 `name` 仍然有效；`make_event<QuoteEvent>(std::move(name), ...)` 之后 `name` 处于被移动状态。
>
> **放进 `std::function` 的开销**
>
> - 一次类型擦除，调用变成间接跳转，通常无法内联；
> - 如果捕获的数据超过小对象缓冲区，会堆分配；
> - `std::function` 要求可复制，捕获了只能移动的类型就放不进去。
>
> **完整可运行代码**：[[学习/2026-10-30/示例代码/03_forwarding|03_forwarding]]，其中 `make_event` 与调用示例都在。
