## 关键观察

| 项目 | 本机数值 | 说明 |
| --- | --- | --- |
| `sizeof(无捕获 lambda)` | 1 | 空类唯一地址 |
| `sizeof(捕获 int 的 lambda)` | 4 | 闭包成员就是一个 int |
| `sizeof(捕获 string 的 lambda)` | 32 | 本机 `std::string` 为 32 字节 |
| `sizeof(std::function<int(int)>)` | 32 | 标准库实现固定 |
| `sizeof(std::optional<char>)` | 2 | 值 + 标志位 |
| `sizeof(std::optional<double>)` | 16 | 8 + 1 + 补齐 |
| `sizeof(variant<Quote,Trade,Ack>)` | 24 | 最大成员 16 + 索引 + 对齐 |
| 不用 `forward` 传右值 | 拷贝 | 形参有名字即左值 |
| 用 `forward` 传右值 | 移动 | 值类别保留 |
