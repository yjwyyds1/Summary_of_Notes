## 怎么运行

每个文件单独编译，在本目录执行，例如：

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic 07_dispatcher.cpp -o 07_dispatcher.exe
.\07_dispatcher.exe
```

如果找不到 g++，可以使用本机已有的 `D:\CLion\bin\mingw\bin\g++.exe`，PowerShell 调用方式见 [[学习/学习导航/2026-10-21-学习导航#6 代码阅读与运行入口|运行说明]]。

教材中故意错误的片段不作为可运行版本，尤其不执行非虚基类删除派生对象等未定义行为。实际验证结果见 [[学习/2026-10-21/示例验证]]。
