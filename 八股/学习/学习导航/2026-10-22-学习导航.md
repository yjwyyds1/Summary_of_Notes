## 术语速查

| 术语 | 先用一句话理解 |
| --- | --- |
| 多态 / 动态绑定 | 同一个调用写法，按对象真实类型执行不同函数 |
| 虚表 vtable | 编译器给每个多态类准备的一张函数地址表（实现细节，不是标准术语） |
| 虚表指针 vptr | 对象里指向自己那张表的指针，常见实现放在对象起始处 |
| 覆盖 override | 派生类用相同签名重新实现基类虚函数 |
| 名字隐藏 | 派生类声明同名成员后，基类所有同名成员被挡住 |
| 静态存储期 | 对象从程序启动就存在，直到程序结束 |
| 对齐 alignment | 对象地址必须是某个值的整数倍 |
| RTTI | 运行期类型信息，`typeid` 与 `dynamic_cast` 依赖它 |
