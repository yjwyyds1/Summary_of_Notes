## 术语速查

| 术语 | 先用一句话理解 |
| --- | --- |
| 序列 / 关联 / 无序容器 | 按位置存 / 按 key 有序存 / 按哈希存 |
| 容器适配器 | 借用别的容器提供受限接口 |
| 迭代器分类 | 输入、输出、前向、双向、随机访问 |
| 失效 | 容器修改后旧迭代器/引用还能不能用 |
| 红黑树 | 近似平衡的二叉搜索树，修改时旋转少 |
| 负载因子 | 元素数 / 桶数 |
| rehash | 重建桶数组、重新分布元素 |
| 堆 | 完全二叉树形状的数组，堆顶是极值 |
| TopK | 从 n 个里取最大/最小的 k 个 |
| 稳定排序 | 相等元素保持原有相对顺序 |
