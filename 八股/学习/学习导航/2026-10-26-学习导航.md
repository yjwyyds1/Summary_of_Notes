## 术语速查

| 词 | 先这样理解 |
| --- | --- |
| fd / 打开文件描述 | 进程内整数取件号 / 保存偏移与状态的打开实例 |
| 短读写 | 本次完成字节数少于请求数 |
| 页缓存 / fsync | 内核暂存文件页 / 请求把文件状态同步到存储 |
| mmap | 把文件页接入进程虚拟地址空间 |
| rename / 目录 fsync | 切换路径名字 / 同步名字所在目录 |
| WAL / 重放 | 先写可恢复记录 / 重启后重新应用有效记录 |
