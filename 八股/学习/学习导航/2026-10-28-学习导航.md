## 术语速查

| 术语 | 初学者先这样理解 |
| --- | --- |
| 翻译单元 | 一个 .cpp 加上预处理后包含进来的内容 |
| 声明 / 定义 | 告知名字与类型 / 真正提供实体或函数体 |
| 模板实例化 | 按具体类型生成或要求具体函数/类 |
| 静态归档 .a | 多个目标文件装在一起，链接时按需要抽取 |
| 动态对象 .so | 程序运行时仍要由装载器找到的依赖 |
| ABI | 二进制层面的符号、调用与对象约定 |
| CMake target | 构建图中的库或程序节点，带有自己的使用要求 |
