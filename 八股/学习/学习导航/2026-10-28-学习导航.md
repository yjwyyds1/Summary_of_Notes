## 术语速查

| 术语 | 先用一句话理解 |
| --- | --- |
| 翻译单元 | 一个 .cpp 加它包含的头文件，预处理后的整体 |
| 目标文件 .o | 机器码 + 符号表 + 重定位信息 |
| 符号 U / T | 未定义（等着链接补）/ 代码段已定义 |
| 静态库 .a | 目标文件归档，链接时复制进程序 |
| 动态库 .so | 运行期装载，程序里只留依赖 |
| PIC | 位置无关代码，动态库需要 |
| ODR | 一个实体在程序里只能有一份定义 |
| core dump | 崩溃时的内存镜像 |
| 尾延迟 | p99/p999，最慢那一小部分的延迟 |
