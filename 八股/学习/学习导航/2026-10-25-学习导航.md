## 术语速查

| 术语 | 先用一句话理解 |
| --- | --- |
| `operator new` | `new` 表达式背后“要一块内存”的函数 |
| placement new | 在已给地址上构造对象，不分配内存 |
| 浅拷贝 / 深拷贝 | 只复制指针 / 连同指针指向的内容一起复制 |
| 三法则 | 析构、拷贝构造、拷贝赋值要一起管 |
| ASan | 编译期插桩的内存错误检测器 |
| 内存池 | 预先要一大块内存，自己切块复用 |
| 分配器 | 容器用来要内存/还内存的组件 |
| AoS / SoA | 一条记录连着放 / 同一字段连着放 |
| 缓存行 | CPU 搬数据的最小单位，x86-64 常见 64 字节 |
| 伪共享 | 多线程写同一行里的不同变量，互相让缓存失效 |
