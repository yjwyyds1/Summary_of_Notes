## 术语速查

| 词 | 先这样理解 |
| --- | --- |
| 缓存行 / 局部性 | 硬件搬运的相邻字节块 / 访问附近或刚用过的数据 |
| AoS / SoA | 按记录排列 / 按字段排列 |
| 伪共享 | 不同变量落在同一缓存行导致的性能干扰 |
| 分配器 / reserve | 存储取得策略 / 提前准备 vector 容量 |
| LRU | 淘汰最久未访问的缓存项 |
| p99 | 按选定算法统计的约 99% 样本不超过的延迟 |

阅读顺序先讲数据，再讲多核写入与分配，最后用 LRU 和测量练习综合判断。所有示例以 C++17 编写；本页不把示例的单次运行当作性能证明。
