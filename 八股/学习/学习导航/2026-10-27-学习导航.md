## 术语速查

| 词 | 初学者先这样理解 |
| --- | --- |
| atomic / mutex | 单个对象的不可分访问 / 一段操作的共同门锁 |
| release / acquire | 发布已写数据 / 读到发布信号后接收数据 |
| relaxed | 保留原子性，不建立周边普通数据的交接顺序 |
| CAS / expected | 旧值匹配才更新 / 失败后保存当前观察值 |
| SPSC / head / tail | 单生产单消费 / 下一出队位 / 下一入队位 |
| ABA / 安全回收 | 数值回来但状态变过 / 等读者离开后才释放节点 |
