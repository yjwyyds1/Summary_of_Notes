# 2026-10-28 示例验证

验证环境：WSL Ubuntu，`g++ (Ubuntu 15.2.0-16ubuntu1) 15.2.0`；另用环境自带 CMake 对最小接口 target 工程构建。源码均保存在 [[学习/2026-10-28/示例代码/README|示例代码目录]]。这是一次构建与运行检查，不等于跨平台正确性证明。

| 检查 | 实际结果 |
| --- | --- |
| 7 份独立 `.cpp` | `g++ -std=c++17 -Wall -Wextra -Wpedantic` 全部编译并运行成功，输出依次为 `demo:300`、`1,7,1`、`42`、`6`、`12`、`6`、`10` |
| GNU 静态归档 | `04_static_archive.cpp` 用 `ARCHIVE_LIBRARY_ONLY` 构建 `.a`；调用者在库前链接成功、在库后按实验预期链接失败 |
| Linux 共享库 | `05_shared_abi.cpp` 用 `-fPIC -shared -DSHARED_LIBRARY_ONLY` 构建 `.so`；调用者以 `LD_LIBRARY_PATH` 指向临时目录后运行成功 |
| 练习故障分支 | `07_link_diagnosis.cpp` 用 `-DDEMO_MISSING_DEFINITION` 可编译 `.o`，后续链接按预期失败 |

所有构建产物放在 WSL 临时目录；笔记目录只保存教学源码和 Markdown。故障分支仅观察编译/链接诊断，没有把未成功链接的文件当程序运行。未测试不同编译器、Windows DLL 搜索、跨 ABI 兼容、库部署安全性与性能。
