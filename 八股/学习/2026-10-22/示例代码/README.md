## 编译命令

统一使用 GCC 13.1、C++17：

```bash
g++ -std=c++17 -O0 -Wall -Wextra 文件名.cpp -o 文件名
```

Windows 下生成的 `*.exe` 在验证完成后已删除，需要时重新编译即可。

## 阅读顺序建议

1. 先看 01，建立“对象里有什么”的直觉；
2. 再看 02，理解构造/析构期间的对象状态；
3. 06 与 07 属于“用得上”的部分：转换与接口约束，配合练习题看。
