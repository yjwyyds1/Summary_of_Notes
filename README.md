# Summary of Notes

个人技术面试与日常学习笔记库。内容用 Obsidian 编写，Git 做版本管理，方向以 C++ 开发为主，偏向量化交易、低延迟、Linux、网络与并发。

## 目录

| 目录 | 内容 |
| --- | --- |
| `八股/` | 每日学习与自测：每天 6 道面试题 + 1 道小练习，学习资料和测试题分开存放 |
| `interview/` | 分科目整理：C++、Linux、操作系统、数据结构与算法、计算机网络、数学考察 |
| `interview/C++_code/` | 各篇笔记配套的 C++ 示例代码，按章节组织 |

## `八股/` 的组织方式

- `学习/YYYY-MM-DD/`：当天专题笔记、`示例代码/`（带详细注释的 `.cpp` + 同名 `.md` 阅读版）和 `示例验证.md`
- `八股测试/YYYY-MM-DD.md`：当天自测题，采用「先答题、再展开答案」的格式
- `题目索引.md`：永久题号、自测分数与实际复习日期
- `知识点台账.md`：已覆盖的知识点，用于跨日查重
- `学习/学习导航/`：按日期汇总的学习入口

## 怎么读

1. 用 Obsidian 把仓库根目录作为 vault 打开，笔记里的 `[[双链]]` 才能正常跳转（GitHub 网页上不会跳）。
2. 部分笔记用 Mermaid 绘制流程图，需要在 Obsidian 中查看。
3. 示例代码基线为 C++17；涉及 POSIX / Linux 接口的示例需要在 Linux 或 MSYS2 环境下编译。

## 说明

- 内容仅供个人学习，技术结论以标准草案与官方文档为准；笔记中保留了资料来源与核对日期。
- 仓库只提交笔记与源码，`.exe`、`build/`、`.idea/`、Obsidian 工作区状态等已在 `.gitignore` 中排除。
- 笔记会持续增补，历史版本保留在 git 提交记录里。
